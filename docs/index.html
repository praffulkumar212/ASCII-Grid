ascii-engine

Zero-dependency ASCII art engine for interactive, theme-adaptive article graphics. One file, embeds with two lines of HTML.

Quick start

<script src="ascii-engine.min.js" defer></script>
<div data-ascii-src="/img/hero.jpg"
     data-ascii-preset="theme-adaptive"
     data-ascii-alt="Portrait of a trader at a terminal"></div>

That's it — the engine auto-initializes every element carrying data-ascii-src. The easiest way to produce a config is the playground (playground/index.html): drop an image, pick a preset, tune, copy the snippet.

Programmatic API

const engine = new ASCIIEngine(container, {
  src: '/img/hero.jpg',
  preset: 'crt',
  glow: 70,               // any option overrides the preset
  alt: 'CRT-styled portrait',
});
engine.render();          // or engine.render(imgElement)
engine.update({ density: 80 });  // cheap — grid is cached
engine.destroy();

Touch devices: hover works via touch-drag; coarse-pointer devices get a slow ambient auto-animation instead. Both respect prefers-reduced-motion (animations render their static frame).

Theming

:root {
  --ascii-fg: currentColor;   /* glyph color (theme mode) */
  --ascii-bg: transparent;    /* container background      */
  --ascii-accent: #4f8cff;    /* hover / pulse effects     */
}

In theme color mode the art is colored purely by CSS variables, so class-based themes and prefers-color-scheme both flip it automatically. Known limitation: source mode with themeBlend>0 bakes colors at render time — re-render on theme switch.

Performance guide

SituationRecommendation
Article thumbnail / hero (≤ ~8k glyphs)dom — full hover interactivity
High density (>150 cols) or heavy noise animationcanvas — cell redraws instead of DOM writes; hover uses highlight semantics
No interactivity neededpre — one text node
Glow > 60%Doubles shadow layers — costs paint time on very large dom grids; fine on canvas

Non-structural updates (contrast, color, dither, glow…) patch glyphs in place and never re-run the sampling pipeline; only src/cols/edgeBlend/aspect changes resample (results are cached per combination).

Accessibility

Always on: the art container is aria-hidden; the required alt renders as a visually-hidden role="img" description; keyboard focus never enters the glyphs; prefers-reduced-motion disables noise, ripple, ambient and entrance animations.
